# InterviewerAgent 项目目录结构

```text
InterviewerAgent/
├── README.md                    # 含 uv sync / docker 起库 / 启动命令
├── CLAUDE.md
├── pyproject.toml / uv.lock     # Python 依赖（uv 管理，已有）
├── docs/
│   ├── course/                  # 课程文档模板（已有）
│   └── design/技术设计方案.md
├── backend/
│   ├── .env.example             # LLM_API_KEY / LLM_MODEL / LLM_BASE_URL / TAVILY_API_KEY / GITHUB_TOKEN / DATABASE_URL / HTTP_PROXY
│   ├── app/
│   │   ├── main.py              # FastAPI 实例、CORS、路由挂载、lifespan(建表、僵尸任务重置)、静态托管+SPA fallback
│   │   ├── config.py            # ★ pydantic-settings：模型名/连接串/密钥统一出口
│   │   ├── api/v1/
│   │   │   ├── resumes.py       # 上传/画像确认/证据查询/重新核实/删除
│   │   │   ├── sessions.py      # 会话管理/跳过/结束/删除
│   │   │   ├── interview.py     # NDJSON 流式接口（幂等 + 并发生成标记）
│   │   │   └── reports.py       # 报告查询
│   │   ├── models/
│   │   │   ├── orm.py           # 4 张表 SQLAlchemy 模型
│   │   │   └── schemas.py       # ★ 四大数据契约（ResumeProfile/EvidenceCard/RiskFlag/InterviewReport）
│   │   ├── common/
│   │   │   ├── logger.py        # 日志配置（沿用参照项目）
│   │   │   ├── db.py            # engine/session（DATABASE_URL → MySQL）
│   │   │   ├── events.py        # ★ NDJSON 事件协议（§5.2，契约冻结对象）
│   │   │   └── storage.py       # uploads/ 文件管理（uuid 命名）
│   │   └── agent/
│   │       ├── llm.py           # ChatOpenAI 工厂（base_url/模型名取自 config，按角色配温度/超时）
│   │       ├── prompts.py       # 人设 + 5 阶段指令 + 2 难度档位 + 防幻觉硬约束
│   │       ├── tools.py         # 4 个 @tool
│   │       ├── research.py      # create_agent 联网核实编排（含硬超时）
│   │       ├── interview.py     # 五阶段状态机 + 单轮流式处理（NDJSON 生成器）
│   │       └── report.py        # 评估报告生成（message_id 引文锚定）
│   ├── static/                  # （构建期）Next.js 静态导出产物，FastAPI 托管
│   └── tests/
│       ├── test_phase_machine.py  # 状态迁移表驱动测试（用例见设计方案 §7）
│       ├── test_tools.py          # 工具单测（httpx mock）
│       ├── test_api.py            # REST/流式接口冒烟
│       └── test_idempotency.py    # 同一 client_msg_id 重发只落一条消息、只生成一次
└── frontend/
    ├── package.json / next.config.ts   # output: "export"
    ├── app/                     # 页面：page.tsx(首页) / prepare / session / report / layout.tsx
    ├── components/              # ChatMessage / ChatInput / EvidenceBadge / PhaseStepper / RadarChart
    ├── lib/                     # api.ts（fetch 封装+流式读取器）/ utils.ts
    └── types/                   # 契约镜像
```
